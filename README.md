A small Python program that writes one word describing the human you work for — a boss, a client, a manager, whoever signs off on your work — to /output/entry.txt.

The word is **Paperweight**: the most important person in the room, reduced to a decorative lump of glass that sits on a desk holding paper down. A status inversion in a single word — funny, fitting, vivid, and it lands with no explanation needed. The word is fixed and deterministic — the same 11-character word every run.

## Run it

```sh
python3 main.py
```
